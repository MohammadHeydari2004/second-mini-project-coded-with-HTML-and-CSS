## 🌟 معرفی پروژه

این پروژه به عنوان یک **نمونه کار (Portfolio)** برای معرفی خدمات یک کتابخانه عمومی توسعه یافته است. هدف اصلی، ارائه یک رابط کاربری مدرن، خوانا و دسترس‌پذیر برای کاربران فارسی‌زبان است که از طریق آن بتوانند با خدمات مختلف کتابخانه، مراحل عضویت، پرسش‌های متداول و راه‌های ارتباطی آشنا شوند.

---

## ✨ ویژگی‌ها

- **طراحی کاملاً راست‌چین (RTL):** سازگار با زبان فارسی و فرهنگ نگارشی ایران.
- **طراحی واکنش‌گرا (Responsive):** بهینه‌سازی شده برای تمام دستگاه‌ها (موبایل، تبلت، دسکتاپ) از عرض ۳۲۰ پیکسل تا بیش از ۲۵۶۰ پیکسل.
- **تایپوگرافی حرفه‌ای:** استفاده از فونت محبوب و استاندارد **وزیرمتن (Vazirmatn)** جهت خوانایی بالا.
- **طراحی مدرن:** بهره‌گیری از گرادیان‌های رنگی، سایه‌ها، Border Radius و انیمیشن‌های نرم (Transitions).
- **معماری متغیرهای CSS (Custom Properties):** استفاده گسترده از CSS Variables برای مدیریت آسان رنگ‌ها، فونت‌ها و فاصله‌ها.
- **سکشن‌های جامع:** شامل معرفی، خدمات، ساعات کاری، قوانین عضویت، پرسش‌های متداول (FAQ) به صورت Accordion و فوتر تماس با ما.
- **پیمایش روان (Smooth Scrolling):** تجربه کاربری دلپذیر هنگام حرکت بین بخش‌های مختلف صفحه.
- **طراحی Sticky Header:** هدر شناور و قابل دسترس در تمام نقاط صفحه.

## 🚀 نحوه اجرا

برای مشاهده پروژه در محیط محلی خود، کافیست مراحل زیر را طی کنید:

1. **کلون کردن مخزن:**

   ```bash
   git clone <repository-url>
   ```

2. **ورود به دایرکتوری پروژه:**

   ```bash
   cd <project-directory>
   ```

3. **اجرای پروژه:**
   - **روش اول:** فایل `index.html` را مستقیماً در مرورگر خود باز کنید.
   - **روش دوم (پیشنهادی):** از افزونه **Live Server** در ویرایشگر VS Code استفاده کنید تا سرور محلی راه‌اندازی شده و تغییرات را به صورت زنده (Hot Reload) مشاهده نمایید.
