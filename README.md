# 📚 کتابخانه خوانش گستر — صفحه راهنمای خدمات

صفحه‌ای تک‌صفحه‌ای (Single Page) برای معرفی خدمات **کتابخانه خوانش گستر**؛ شامل معرفی کتابخانه، خدمات، ساعات کاری، قوانین عضویت، پرسش‌های متداول و راه‌های ارتباطی.

این پروژه صرفاً با **HTML5** و **CSS3 خالص** ساخته شده و از هیچ فریمورک، کتابخانه یا جاوااسکریپتی استفاده نمی‌کند.

## 🚀 نحوه اجرا

نیازی به نصب یا Build نیست:

1. پروژه را دانلود یا کلون کنید.
2. فایل `index.html` را در مرورگر باز کنید.

> 💡 برای تجربه‌ی بهتر، از افزونه‌ی **Live Server** در VS Code استفاده کنید تا صفحه با هر تغییر، به‌صورت خودکار رفرش شود.
>
> ⚠️ ساختار پوشه‌ها را تغییر ندهید؛ مسیر فایل‌های CSS و تصاویر به‌صورت نسبی تعریف شده‌اند.

## ✨ ویژگی‌های فنی

- 🧩 **HTML معنایی (Semantic)** — استفاده از تگ‌های `header`، `main`، `section`، `table`، `blockquote`، `address`، `time` و…
- 📱 **کاملاً واکنش‌گرا** — پشتیبانی از ۷ بازه‌ی نمایشی، از ۳۲۰ پیکسل تا ۲۵۶۰ پیکسل و بالاتر
- 🎨 **سیستم طراحی مبتنی بر CSS Variables** — تمام رنگ‌ها، فونت‌ها، فاصله‌ها و شعاع‌ها در `:root` به‌صورت Design Token تعریف شده‌اند
- 🔤 **فونت وزیرمتن (Vazirmatn)** — بارگذاری از Google Fonts
- 🧭 **هدر ثابت گرد (Pill-shaped)** — همراه با اسکرول نرم و `scroll-padding-top` هماهنگ با ارتفاع هدر
- 🙈 **آکاردئون بدون جاوااسکریپت** — با استفاده از المان بومی `<details>` و `<summary>`
- 📊 **جدول استاندارد** — با `caption`، `thead`، `tbody`، `tfoot` و ردیف‌های یک‌درمیان رنگی
- 🌈 **طراحی گرادیانی** — هر بخش رنگ‌بندی اختصاصی خود را دارد

## 📱 نقاط شکست (Breakpoints)

| بازه | تغییرات اصلی |
|---|---|
| `≥ 1440px` | محدود شدن عرض محتوا به ۱۶۰۰px و وسط‌چین شدن |
| `≤ 1439px` | کاهش فاصله‌های کناری صفحه (Gutter) |
| `≤ 1023px` | هدر تمام‌عرض، ستونی شدن بخش‌های دو‌ستونه |
| `≤ 767px` | کاهش اندازه‌ی فونت و padding جدول و فوتر |
| `≤ 424px` | تنظیم دقیق‌تر فاصله‌ها و فونت‌ها |
| `≤ 374px` | فونت‌های کوچک‌تر برای موبایل‌های کوچک |
| `≤ 319px` | حداقل فاصله‌ها برای باریک‌ترین صفحه‌ها |

## 🎨 سیستم طراحی (Design Tokens)

خلاصه‌ای از متغیرهای اصلی تعریف‌شده در `:root`:

| گروه | نمونه متغیرها | توضیح |
|---|---|---|
| رنگ برند | `--color-primary`، `--color-secondary` | رنگ‌های اصلی و حالت Hover |
| رنگ خنثی | `--color-gray-50` تا `--color-gray-900` | طیف خاکستری برای متن و پس‌زمینه |
| گرادیان‌ها | `--gradient-logo`، `--gradient-footer` و… | گرادیان اختصاصی هر بخش |
| تایپوگرافی | `--font-size-*`، `--line-height-*` | اندازه‌ها با `clamp()` برای عنوان‌ها |
| فاصله‌ها | `--space-1` تا `--space-32` | مقیاس یکنواخت از ۰٫۲۵ تا ۸rem |
| شعاع | `--radius-sm` تا `--radius-full` | گردی گوشه‌ها |
| سایه | `--shadow-sm` / `md` / `lg` | سه سطح سایه |
| چیدمان | `--header-offset`، `--page-gutter` | ارتفاع هدر و فاصله‌ی کناری صفحه |

## 🛠️ شخصی‌سازی

- **تغییر رنگ‌بندی:** کافی است مقدار متغیرها را در بخش `:root` فایل `CSS/Style.css` تغییر دهید؛ کل صفحه به‌روز می‌شود.
- **تغییر محتوا:** تمام متن‌ها داخل `index.html` قرار دارند.
- **افزودن بخش جدید:** یک `<section>` با `id` یکتا بسازید و لینک آن را به `.nav_list` اضافه کنید.

## ♿ دسترس‌پذیری

- تعیین `lang="fa"` و `dir="rtl"` برای صفحه
- متن جایگزین (`alt`) برای تصاویر

- آکاردئون بومی و کیبورد-فرندلی با `<details>`
- کنتراست مناسب رنگ متن و پس‌زمینه
